# API specification

Base URL (local dev): `http://localhost:8000`
Interactive docs (auto-generated by FastAPI): `http://localhost:8000/docs`

## Triggers

### `GET /triggers`
List all defined triggers with current status.

**Query params:** `country`, `hazard`, `status` (optional filters)

**Response 200**
```json
[
  {
    "trigger_id": "KE-MSB-DROUGHT-01",
    "country": "Kenya",
    "admin_unit": "Marsabit County",
    "hazard": "drought",
    "status": "arming",
    "conditions": [ { "indicator": "seasonal_forecast_probability_below_normal", "current_value": 0.58, "threshold": 0.60, "operator": ">=" } ]
  }
]
```

### `POST /triggers`
Define a new trigger. Body: see `TRIGGER_SCHEMA.md`.

### `GET /triggers/{trigger_id}`
Full detail for one trigger, including condition history and the LSTM's current arming probability.

## Predictions

### `GET /predict/{admin_unit}`
Returns the anticipation model's forecast for every indicator tracked in that admin unit over the next 14 days.

**Response 200**
```json
{
  "admin_unit": "Marsabit County",
  "forecast": [
    { "day": 1, "indicator": "seasonal_forecast_probability_below_normal", "predicted_value": 0.59, "confidence": 0.81 },
    { "day": 7, "indicator": "seasonal_forecast_probability_below_normal", "predicted_value": 0.63, "confidence": 0.74 }
  ]
}
```

## Activation

### `POST /activate/{trigger_id}`
Manually fires the activation orchestrator for a triggered trigger (used in the demo to force an activation without waiting for real data to cross a threshold). In production this is called automatically by the trigger engine.

**Response 200**
```json
{ "dispatch_id": "d-88421", "trigger_id": "KE-MSB-DROUGHT-01", "dispatched_at": "2026-07-19T09:14:00Z", "delivery_route": ["gateway", "village_a", "village_c"] }
```

### `POST /acknowledge/{dispatch_id}`
Called by (or simulated on behalf of) the responsible institution to confirm receipt and log the action taken.

**Body**
```json
{ "acknowledged_by": "Kenya NDMA, Marsabit sub-office", "action_taken": true, "notes": "Cash transfer initiated" }
```

## Mesh network

### `GET /mesh/topology`
Current node graph — used to render the topology view.

### `GET /mesh/status`
Per-node online/offline state and last-seen timestamp.

### `POST /mesh/simulate`
Runs a mesh delivery simulation for a given dispatch, returning the hop-by-hop path and timing — used by both the backend orchestrator and the frontend's propagation-log visualization.

## Scorecard

### `GET /institutions/scorecard`
Average time-to-acknowledge and time-to-action per institution, plus the anomaly model's current risk flag (on_track / slow / overdue) for each.

**Response 200**
```json
[
  { "institution": "Kenya NDMA, Marsabit", "avg_ack_hours": 1.2, "status": "on_track" },
  { "institution": "Ethiopia NDRMC, Dolow border", "avg_ack_hours": 14.0, "status": "overdue" }
]
```
